# Dylan Messerly — Portfolio Site (Vanilla HTML)

This is the original version of my personal portfolio website, built with vanilla HTML, CSS, and JavaScript.

This version has since been converted to a Vite + React + TypeScript application on the `react-convert` branch.

## Tech Stack

- HTML5
- CSS3 (custom animations, typewriter effect, gradient background)
- JavaScript (IntersectionObserver, smooth scrolling, form handling)
- Bootstrap 5 (CDN)
- Gradio (embedded AI Career Chatbot)
- Formspree (contact form)

## File Structure

```
index.html              # Main portfolio page
view_resume.html        # Resume PDF viewer
assets/
├── css/
│   └── style.css       # All styles
├── images/             # Site images
├── dylan_messerly_resume.pdf
js/
└── script.js           # All JavaScript behaviors
```

## Deployment

This version was deployed directly from the `main` branch via GitHub Pages — no build step required.

## React Version

See the `react-convert` branch for the modernized Vite + React + TypeScript version of this site.
